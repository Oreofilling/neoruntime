NEORUNTIME APPLICATION MANIFEST

NeoApp app.yaml 配置参考

面向应用开发、打包和测试人员，说明应用导入页面各字段与 YAML 的映射、校验规则以及当前版本限制。

适用分支：release/v1.1.0 API：v1 单容器向导 + YAML 扩展 更新：2026-09-29

1. 适用范围

基础信息

应用 ID、名称、版本、描述和镜像标识。

资源分配

CPU 与内存限制。

模型配置

系统模型、自带 AMPK 模型和推理配额。

权限与高级配置

视频、事件、网络、环境变量、挂载及运行策略。

来源依据：当前 release/v1.1.0 的 app-manager manifest 解析器、platform-api 导入接口和 Web 导入表单。
重要：表单只覆盖常用单容器字段。YAML 中的未知字段可能被保留，但不代表运行时支持；不要依赖未在本文或代码结构中声明的字段。

2. 最小可用配置

单容器应用必须提供固定 API 版本、合法类型、三项基础身份信息以及镜像。

apiVersion: v1
kind: Application
metadata:
  id: my-app
  name: My Application
  version: 1.0.0
spec:
  image: docker.io/example/my-app:1.0.0
最小规则：apiVersion 必须为 v1；kind 可为 Application、ModelService 或 BusinessService。

3. 推荐完整示例

以下示例覆盖导入表单能够编辑的全部字段，并展示 YAML 中仍支持、但暂未在表单展示的设备权限。

apiVersion: v1
kind: Application

metadata:
  id: parking-lot
  name: Parking Lot Analytics
  version: 1.2.5
  description: Vehicle detection and parking analytics
  author: CamThink
  email: support@example.com

spec:
  image: docker.io/example/parking-lot:1.2.5

  resources:
    cpu: "50%"
    memory: "512Mi"

  models:
    detector:
      id: yolov8n
      required: true
    custom_classifier:
      id: parking_classifier
      path: /opt/models/parking_classifier.bin
      required: false

  permissions:
    video:
      - main
    inference:
      max_qps: 10
      max_concurrent: 2
      allow_register_model: false
    events:
      publish:
        - parking/events
      subscribe:
        - camera/status
    network:
      mode: isolated
      inbound: []
    # v1.1.0 导入表单暂不展示设备控制，但 YAML 仍支持：
    device:
      light: false
      ir_cut: false
      ptz: false
      lens: false

  env:
    - name: LOG_LEVEL
      value: info
    - name: CONFIG_PATH
      value: /app/config/config.json

  volumes:
    - host: /data/aipc-data/apps/parking-lot/config
      container: /app/config
      readonly: false

  autostart: true
  restart_policy: on-failure
  security:
    no_new_privileges: true
    readonly_rootfs: true
模型权限合并：spec.models 中声明的模型 ID 会在解析时自动合并进 permissions.inference.models，通常无需手工重复填写。

5. 基础信息

字段要求校验与说明
apiVersion 必填固定 v1其他值直接拒绝。
kind 必填Application / ModelService / BusinessService区分大小写。
metadata.id 必填 表单^[A-Za-z0-9][A-Za-z0-9._-]*$作为目录和运行时身份；上传 app.yaml 或 .neoapp 后不可在表单修改。
metadata.name 必填 表单非空字符串前后全为空白视为无效。
metadata.version 必填 表单非空字符串推荐使用语义化版本，例如 1.2.5。
metadata.description 可选 表单字符串应用说明。
metadata.author / email 可选字符串YAML 支持，当前表单不编辑。
spec.image 单容器必填OCI 镜像引用例如 registry/repo:tag 或 repo@sha256:…；.neoapp 上传后不可修改。
身份保护：对于上传的 .neoapp，后端会拒绝修改 metadata.id；单容器包还会拒绝修改 spec.image，避免 app.yaml 与 image.tar 身份不一致。

6. 资源分配

字段支持格式示例校验
spec.resources.cpu百分比或正数核数"50%"、"0.5"、"2"必须大于 0；表单保留用户输入的核数或百分比写法，不做自动换算。超过 1 核只提示设备容量警告，不是硬上限。
spec.resources.memory正整数 + Ki/Mi/Gi/K/M/G，或纯字节数"256Mi"、"1Gi"必须大于 0；超过 4GiB 只提示设备容量警告，不是硬上限。
字符串建议：CPU 和内存值建议加引号，避免 YAML 自动类型推断导致格式变化。内存数值必须为整数，不能写 0.5Gi。

7. 模型配置

7.1 模型依赖

spec:
  models:
    detector:                 # 别名，生成 AIPC_MODEL_detector
      id: yolov8n             # 平台模型 ID
      required: true          # 缺失时阻断安装
    classifier:
      id: custom_classifier
      path: /opt/models/custom_classifier.bin
      required: false
字段规则
模型别名匹配 ^[A-Za-z_][A-Za-z0-9_]*$；不能使用 HOST_PREFIX、APP_ID、APP_ROLE、CONTAINER_NAME。
id必填；作为模型运行时身份和注入容器的环境变量值。
path可选；镜像内绝对、规范路径，必须以 .bin 结尾，表示 AMPK 模型包。
requiredtrue 时，设备没有该模型且没有 path 回退包会阻断安装；默认 false。
同一模型多个别名允许，但同一 id 不能声明互相冲突的 path。
不再支持：spec.models.<alias>.type 会被明确拒绝。自带模型的后处理类型来自 AMPK .bin 包元数据，不再由 app.yaml 声明；裸 .hef 路径也不支持。

7.2 推理配额

  • permissions.inference.max_qps：必须是 ≥ 0 的整数；没有固定配置上限。
  • permissions.inference.max_concurrent：必须是 ≥ 0 的整数；没有固定配置上限。
  • permissions.inference.allow_register_model：允许运行时动态注册模型，开启时会显示安全警告。
  • permissions.inference.models：显式授权列表；spec.models 中的 ID 会自动合并进去。
配额说明：0 表示使用运行时默认值或不设对应限额。前后端不设置统一的最大值；实际可用能力仍受设备 CPU、NPU、内存和运行时容量限制，应在目标设备上验证。

8. 权限设置

路径类型规则表单状态
permissions.video字符串数组设备视频流 ID；不存在的流会提示警告。可编辑
permissions.events.publish字符串数组不得为空或重复。可编辑
permissions.events.subscribe字符串数组不得为空或重复，可使用平台支持的主题匹配规则。可编辑
permissions.network.mode字符串isolated 或 host；host 共享主机网络并提示风险。可编辑
permissions.network.inbound端口数组1–65535、不得重复，且仅允许在 mode: host 下使用。可编辑
permissions.network.outbound字符串数组YAML 支持；当前表单不编辑。仅 YAML
permissions.device对象light、ir_cut、ptz、lens、gpio.read/write。暂时隐藏
v1.1.0 限制：设备控制权限目前只在导入表单中隐藏，YAML 字段仍会被解析和保留。不要因为页面看不到就假定原配置已被清除。

9. 高级配置

9.1 环境变量

  • name 必须匹配 ^[A-Za-z_][A-Za-z0-9_]*$，同一清单内不得重复。
  • value 是字符串；${VAR} 会尝试从 app-manager 进程环境展开，未定义时保留原文本。

9.2 数据卷

spec:
  volumes:
    - host: /data/aipc-data/apps/my-app/config
      container: /app/config
      readonly: false
  • host 和 container 都必须是绝对规范路径，不能包含 .、.. 或冗余分隔。
  • 同一个容器目标路径不能重复挂载。

9.3 启动、安全与重启

字段取值与默认行为
autostart布尔值；安装后是否自动启动。
restart_policyalways、on-failure、no；兼容输入 on_failure、never，保存解析后归一化。
restart_max_retries可选；0 表示无限重试。
security.no_new_privileges默认 true；设为 false 允许权限提升。
security.readonly_rootfs默认 true；设为 false 会产生可写根文件系统警告。

10. YAML 专用高级字段

以下字段由 manifest 结构支持，但不在当前五页导入表单中完整编辑。

区域关键字段说明
健康检查healthcheck.enabled/type/command/path/port/interval/timeout_seconds/retries支持 command、http、tcp 形态；按类型提供命令或端口。
自动重启兼容配置auto_restart.*旧版兼容字段；新配置优先使用 restart_policy。
插件plugin.capabilities
plugin_dependencies		声明 grpc/event/both 能力；事件主题必须被 permissions.events 覆盖。
多容器containers、networking、lifecycle必须且只能有一个 role=main；sub 容器不能声明平台权限。
开发模式dev.enabled/watch_path/sync/reload_signal/debug_port用于本地热重载，不建议用于生产包。
多容器提示：多容器模式不使用顶层 spec.image；每个 spec.containers.<name>.image 必须存在，并通过 role、端口、挂载、生命周期顺序和网络规则校验。

11. NeoApp 包约束

my-app.neoapp                 # tar.gz 格式
├── app.yaml                  # 必须，最大 4MiB
├── image.tar                 # 必须，OCI/Docker 镜像归档
└── SHA256SUMS                # 可选
  • .neoapp 中必须同时存在 app.yaml 和 image.tar。
  • 上传后清单位于请求私有 staging 目录；取消、失败或超时会按任务整体清理。
  • 安装已有应用 ID 时，必须显式确认覆盖；不能通过偷偷修改包身份绕过。
  • YAML 和表单都会在安装前校验；后端解析器是最终判定。

12. 常见错误

错误现象原因修复
metadata.id is invalidID 含空格、斜杠或路径穿越字符。改为字母/数字开头，只使用字母、数字、点、下划线和连字符。
invalid CPU/memory format使用 0、负数、小数内存或未知单位。例如 "50%"、"512Mi"。
model path must be a .bin填写了 .hef 或相对路径。打包为 AMPK .bin，并填写镜像内绝对路径。
required model unavailable设备不存在必需模型，且应用未携带模型包。先导入模型，或填写有效 path。
network.inbound requires hostisolated 模式配置了入站端口。清空 inbound，或在理解风险后切换 host。
duplicate environment/volume环境变量名或容器挂载目标重复。删除重复项。
metadata.id/spec.image is immutable上传 .neoapp 后修改了包身份字段。重新制作包；不要在导入流程中改身份。

13. 发布前检查清单

  • apiVersion、kind、ID、名称、版本和镜像完整。
  • ID 与镜像内应用身份一致，升级包没有更改既有应用 ID。
  • CPU、内存均为正值，资源上限符合设备能力。
  • 所有 required 模型在设备存在，或包内提供有效 AMPK .bin。
  • 视频流 ID、事件主题、网络模式和端口经过目标设备验证。
  • 环境变量名唯一，挂载路径为绝对规范路径，容器目标不重复。
  • host 网络、动态模型注册、可写 rootfs 等警告均经过明确评审。
  • .neoapp 同时包含 app.yaml 和 image.tar，并在目标版本设备完成安装验收。
