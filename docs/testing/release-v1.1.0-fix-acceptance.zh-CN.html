3. 通用前置条件与证据

前置条件

  • Hailo-15 NE503 实机已安装基于 4762a397 的发布包。
  • 准备包含 main/sub/third 的多流 Profile，至少一个 H.264 和一个 H.265 场景。
  • 测试端具备 Web 管理员会话、SSH、curl、jq、播放器或 ffprobe。
  • 准备大体积 .neoapp 和镜像 tar，以便在上传过程中执行取消。
  • 准备 1.12.0 构建环境；定制兼容范围测试需有 GitHub Actions 手工触发权限。

每个失败必须保留

  • 用例 ID、精确时间、设备 SN、发布包 SHA256。
  • 请求与响应正文、浏览器 Console / Network HAR。
  • journalctl -u aipc-camera-daemon 对应时间窗日志。
  • GET /api/v1/media/status 前后快照。
  • 黑屏、方向、流身份问题的视频或截图；必要时附 dmesg。

命令约定

export AIPC_BASE="https://<device-ip>"
export TOKEN="<admin-token>"   # 若使用 Cookie 会话，请替换 curl 的鉴权参数
curl -sk -H "Authorization: Bearer $TOKEN" "$AIPC_BASE/api/v1/media/status" | jq
journalctl -u aipc-camera-daemon -f
