# 错误与状态码

## 响应信封

所有接口返回相同的 JSON 信封：

```json
{
  "code": 0,               // 业务码 —— 0 表示成功
  "message": "Success",    // 人类可读的摘要
  "data": { },             // 成功时的载荷（失败时缺失或为 null）
  "error": {               // 可选，失败时出现
    "type": "validation",  // 类别：validation | auth | service | resource | system
    "detail": "..."        // 具体出错原因
  }
}
```

请始终根据 `code` 而非 `message` 做分支——message 面向人类、可能变化；code 才是契约。

## HTTP 状态与业务码

HTTP 状态是粗粒度信号，业务 `code` 才是精确信号：

| HTTP | 典型业务码 | 含义 |
| --- | --- | --- |
| 200 | `0` | 成功。 |
| 400 | `1001` `1002` `1003` `1004` `1005` | 校验失败——JSON 格式错误、参数缺失/非法、时间戳过期。 |
| 401 | `2000` `2002` `2003` | Bearer 令牌缺失、无效、过期或已吊销；登录凭据错误。 |
| 403 | `2001` | 已认证但无权限。 |
| 404 | `4000` `5000` `6000` `8000` `10000` | 引用的资源（应用、模型、文件、进程……）不存在。 |
| 409 | `4001` `6004` `6005` | 冲突——已存在，或应用状态不允许该操作。 |
| 5xx | `3000`–`3004` 等 | 服务不可用/超时、后端 gRPC 或数据库错误。 |

## 业务码注册表

业务码按千位分段；分段含义稳定，具体代码只增不改。

| 分段 | 分组 | 代码 |
| --- | --- | --- |
| `0` | 成功 | `0` 成功 |
| `1xxx` | 通用/请求错误 | `1000` 未知错误 · `1001` 无效请求 · `1002` JSON 格式错误 · `1003` 缺少参数 · `1004` 参数非法 · `1005` 时间戳超出窗口 |
| `2xxx` | 认证与授权 | `2000` 未授权 · `2001` 禁止 · `2002` 令牌过期 · `2003` 令牌无效 |
| `3xxx` | 服务/基础设施 | `3000` 服务不可用 · `3001` 服务超时 · `3002` 服务错误 · `3003` gRPC 错误 · `3004` 数据库错误 |
| `4xxx` | 资源错误 | `4000` 不存在 · `4001` 已存在 · `4002` 资源耗尽 · `4003` 操作失败 |
| `5xxx` | AI/模型错误 | `5000` 模型不存在 · `5001` 模型加载失败 · `5002` 推理错误 · `5003` 模型格式非法 |
| `6xxx` | 应用管理错误 | `6000` 应用不存在 · `6001` 安装失败 · `6002` 启动失败 · `6003` 停止失败 · `6004` 应用已在运行 · `6005` 应用未运行 |
| `7xxx` | 设备错误 | `7000` 设备错误 · `7001` 云台错误 · `7002` 摄像头错误 · `7003` GPIO 错误 |
| `8xxx` | 文件/存储错误 | `8000` 文件不存在 · `8001` 上传失败 · `8002` 删除失败 · `8003` 存储已满 · `8004` 拒绝访问 |
| `9xxx` | SSH 错误 | `9000` 配置错误 · `9001` 服务错误 |
| `10xxx` | 进程错误 | `10000` 进程不存在 · `10001` 终止失败 |

权威列表位于 `platform/platform-api/handlers/response.go`；[API 参考](/zh/api-reference)中各操作文档只描述成功响应，本文所述的 400/401 行为适用于每个写接口，即使未逐一标注。

## 示例：校验失败

```bash
curl -k -X POST https://HOST/api/v1/ai/models \
  -H "Authorization: Bearer eyJ..." \
  -H 'Content-Type: application/json' \
  -d '{}'
```

```json
{
  "code": 1003,
  "message": "Missing required parameter",
  "error": { "type": "validation", "detail": "path is required" }
}
```

## 示例：令牌过期

```json
{
  "code": 2002,
  "message": "Token has expired",
  "error": { "type": "auth", "detail": "re-login required" }
}
```
